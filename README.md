# Плоттер Xiao

Локальная рабочая панель для раскроя на рулонном плоттере Xiao. В ней можно открыть чертёж, разложить детали на полотне, проверить КИМ и порядок реза, а затем выгрузить DXF или передать проходы совместимому контроллеру. Чертежи обрабатываются на компьютере оператора. Для раскладки и симуляции достаточно запустить панель без подключения к станку.

## Возможности

- **Импорт DXF и DWG.** Панель учитывает единицы чертежа и восстанавливает замкнутые контуры, когда их можно однозначно собрать из отдельных линий. Контур, отверстия и насечки перемещаются вместе с деталью.
- **Автораскладка на рулоне.** Задайте ширину полотна, зазор, отступы и правила поворота. Панель сравнивает порядки размещения и использует свободные места между контурами и рядом с длинными деталями. Она учитывает рабочий проход до 2450 мм. Из пригодных вариантов выбирается самый короткий, при равной длине — вариант с меньшим числом проходов.
- **Ручная правка.** При перетаскивании детали магнитятся к соседним контурам с заданным зазором. Панель проверяет зазоры и отступы и пересчитывает шаг протяжки после правки. Правый клик по детали открывает поворот направо, налево или на произвольный угол с помощью ручки на полотне. Правки можно отменить.
- **Проверка раскроя.** Панель показывает коэффициент использования материала (КИМ), длину реза и холостого хода, оценку времени и границы проходов. В симуляции можно просмотреть порядок реза, насечки и места продолжения длинных контуров.
- **Работа со станком.** При совместимом профиле контроллера панель передаёт проходы по одному, показывает прогресс реза и сохраняет журнал. Всю раскладку можно экспортировать в DXF и открыть в штатной программе Xiao.

## Запуск на Windows

1. Скачайте Windows ZIP из раздела **Releases** и распакуйте его целиком. Для запуска из GitHub-репозитория сначала скопируйте `research/machine-profile.example.json` в `research/machine-profile.json`.
2. Запустите `Запустить плоттер.cmd`. Панель откроется в браузере. На Windows x64 для первой установки нужны Python 3.10 или новее и доступ к PyPI. Для импорта DWG лаунчер скачивает GNU LibreDWG и проверяет контрольную сумму.
3. Откройте DXF или DWG, проверьте масштаб, выполните автораскладку и просмотрите проходы в симуляции. Для передачи на станок настройте профиль и проверьте задание на штатном пульте по [инструкции оператора](web-plotter/README.md).

## Профиль станка и рабочие данные

Профиль хранится в `research/machine-profile.json`. В нём задаются IPv4 контроллера, рабочие размеры по X и Y и путь к установленной Xiao. Если ход Z подтверждён на станке, его можно указать в `observedControllerConfiguration.zTravelMm`. Прямая загрузка зависит от контроллера и настроек Xiao. В примере профиля указан адрес компьютера оператора для локального запуска.

Сохранённая раскладка и журнал находятся в каталоге `%LOCALAPPDATA%\Plotter`. Для обновления остановите старый локальный сервер, распакуйте новую версию в отдельную папку и перенесите свой профиль станка. При следующем запуске панель откроет сохранённую раскладку.

## Структура проекта

| Код в `web-plotter/` | Назначение |
| --- | --- |
| `static/` | Интерфейс, полотно для редактирования и симуляция |
| `cad.py` | Импорт чертежей и восстановление замкнутых контуров |
| `nesting.py`, `rect_packing.py`, `contour_packing.py` | Поиск раскладки с учётом поворотов, зазоров и проходов |
| `cut_plan.py`, `cut_metrics.py`, `route_optimizer.py` | План проходов, КИМ и оптимизация маршрута реза |
| `server.py`, `controller.py`, `xiao_job.py` | Локальный HTTP-сервер, связь с контроллером и кодирование заданий Xiao |

## Тестирование и сборка ZIP

Из корня репозитория установите зависимости и запустите тесты.

```powershell
python -m pip install -r .\web-plotter\requirements.txt
python -m unittest discover -s web-plotter
```

Для сборки укажите номер версии и каталог назначения. Скрипт создаёт ZIP с исходным кодом, лаунчером и примером профиля и выводит SHA-256 архива.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\package-release.ps1 -Version 1.3.0 -OutputDirectory .\dist
```
