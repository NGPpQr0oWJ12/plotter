# Сборка и установка

Архив содержит исходный код панели, тесты, Windows-лаунчер и пример настроек. Программа Xiao, её конфигурация, исходные чертежи, журналы станка и данные рабочего места в архив не входят.

Для сборки из корня проекта запустите команду, подставив согласованный номер релиза.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\package-release.ps1 -Version 1.5.1 -OutputDirectory .\dist
```

Параметр `-OutputDirectory` задаёт каталог архива. Скрипт выводит путь к архиву и его контрольную сумму SHA-256.

На Windows x64 распакуйте архив целиком и запустите `Запустить плоттер.cmd`. Для первой установки нужен Python 3.10 или новее. Лаунчер устанавливает зависимости из PyPI. Для импорта DWG он также скачивает LibreDWG и сверяет контрольную сумму. Импорт DXF и симуляция доступны без подключения станка.

Для подключения к станку закройте программу и откройте `research/machine-profile.json` в распакованном архиве:

- `observedComputerConfiguration.machineIp` — IPv4 контроллера. В примере это адрес самого компьютера `127.0.0.1`.
- `observedComputerConfiguration.workrectMm` — рабочий ход по X и Y в миллиметрах. Сверьте значения со штатным пультом.
- `observedControllerConfiguration.zTravelMm` — рабочий ход Z в миллиметрах. Оставьте ноль, если значение не подтверждено.
- `software.path` — путь к уже установленной программе Xiao. В JSON обратные слэши пути удваиваются.

Подключение и прямая загрузка зависят от версии платы и профиля, установленного вместе с Xiao. Подготовка раскладки и экспорт DXF доступны отдельно. Подробности работы описаны в [инструкции панели](web-plotter/README.md).

Перед обновлением остановите старый локальный сервер. Для сохранения настроек скопируйте свой профиль из предыдущей версии в новый каталог. Раскладки и журнал находятся в каталоге данных приложения Windows и доступны после установки новой версии.

## Общая панель в локальной сети

Для ПК оператора запустите `Plotter-Companion-Setup-*-x64.exe` двойным щелчком под учётной записью оператора. В установщик для этой сети уже включены Python, адрес сервера и сертификат для соединения помощника с сервером. При первой установке укажите IP контроллера и подтвердите размеры рабочего поля. Можно выбрать установленный `xiao.exe`, чтобы подставить IP из настроек Xiao. Установщик откроет панель станка и добавит ярлык «Plotter» в меню «Пуск».

Разверните веб-приложение по [инструкции для Ubuntu](deploy/README.md). Центральная панель хранит общую раскладку. Управление станком и журнал реального раскроя доступны на компьютере оператора. Другим компьютерам достаточно браузера и HTTP-адреса панели для общей раскладки и демо-режима.

При установке помощника остановите станок и закройте прежнюю локальную панель. Для установки из архива с исходным кодом передайте установщику сертификат сервера в PEM.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\web-plotter\install-companion.ps1 -CentralUrl 'https://plotter.example.invalid' -CentralCa 'C:\путь\central-ca.pem' -ProfilePath 'C:\путь\machine-profile.json'
```

Укажите HTTPS-адрес сервера и профиль с настройками рабочего станка. Установщик запустит помощник сразу и добавит его в автозапуск при входе этого пользователя в Windows. Панель станка открывается через ярлык «Plotter» и использует ту же общую раскладку.

## Обновление помощника

Версия отображается рядом с логотипом. В панели станка появится кнопка «Обновить», когда в публичном репозитории GitHub выйдет более новый стабильный релиз с архивом помощника. Для проверки и скачивания нужен интернет. Вход в GitHub и GitHub CLI не требуются начиная с версии 1.5.1.

Завершите раскрой и выключите управление перед обновлением. Помощник сохранит профиль, журнал и адрес сервера. При неудачном запуске новой версии Windows вернёт прежнюю.

Скрипт `build-companion-setup.ps1` собирает установщик для новых ПК и универсальный архив `plotter-companion-v<версия>-windows-x64.zip` для обновления. При публикации приложите архив к стабильному релизу с тегом `v<версия>`. Обновление помощника не меняет версию сервера Ubuntu.
