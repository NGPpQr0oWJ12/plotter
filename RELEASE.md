# Сборка и установка

Архив содержит исходный код панели, тесты, Windows-лаунчер и пример настроек. Программа Xiao, её конфигурация, исходные чертежи, журналы станка и данные рабочего места в архив не входят.

Для сборки из корня проекта запустите команду, подставив согласованный номер релиза.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\package-release.ps1 -Version 1.3.0 -OutputDirectory .\dist
```

Параметр `-OutputDirectory` задаёт каталог архива. Скрипт выводит путь к архиву и его контрольную сумму SHA-256.

На Windows x64 распакуйте архив целиком и запустите `Запустить плоттер.cmd`. Для первой установки нужен Python 3.10 или новее. Лаунчер устанавливает зависимости из PyPI. Для импорта DWG он также скачивает LibreDWG и сверяет контрольную сумму. Импорт DXF и симуляция доступны без подключения станка.

Для подключения к станку закройте программу и откройте `research/machine-profile.json` в распакованном архиве:

- `observedComputerConfiguration.machineIp` — IPv4 контроллера. В примере это адрес самого компьютера `127.0.0.1`.
- `observedComputerConfiguration.workrectMm` — рабочий ход по X и Y в миллиметрах. Сверьте значения со штатным пультом.
- `observedControllerConfiguration.zTravelMm` — рабочий ход Z в миллиметрах. Оставьте ноль, если значение не подтверждено.
- `software.path` — путь к уже установленной программе Xiao. В JSON обратные слэши пути удваиваются.

Подключение и прямая загрузка зависят от версии платы и профиля, установленного вместе с Xiao. Подготовка раскладки и экспорт DXF доступны отдельно. Подробности работы описаны в [инструкции панели](web-plotter/README.md).

Перед обновлением остановите старый локальный сервер. Для сохранения настроек скопируйте свой профиль из предыдущей версии в новый каталог. Раскладки и журнал находятся в каталоге данных приложения Windows и доступны после установки новой версии.
